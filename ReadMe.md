# Electron React SQLite Todo App

A lightweight desktop todo application built with **Electron**, **React**, **Vite**, **Tailwind CSS**, and **DaisyUI**, backed by a local **SQLite** database using `better-sqlite3`.

---

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your system.

### Installation

1. Clone or download this repository.
2. $ npm install
3. $ npm run dev
